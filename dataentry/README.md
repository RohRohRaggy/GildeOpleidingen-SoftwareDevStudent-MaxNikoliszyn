**# Urenregistratie Applicatie**



Een simpele CLI tool om gewerkte uren op te slaan in een CSV bestand voor database import.



**## Gebruik**

1\. Start het script via de terminal: `python main.py`

2\. Beantwoord de vragen over je werkdag.

3\. De data wordt toegevoegd aan `uren.csv`.



**## Bestanden**

\- `main.py`: De broncode van de applicatie.

\- `uren.csv`: Het bestand waarin de uren worden opgeslagen.
